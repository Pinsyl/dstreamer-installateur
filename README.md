# Installateur DStreamer

Installateur Android autonome (APK) qui s'installe directement sur un Google TV
Streamer ou un Firestick (sideload via l'appli Downloader). Une fois ouvert, il
installe l'appli Raccoon et remplit automatiquement l'usager et le mot de passe
saisis dans l'appli.

Les fichiers .apk publiés sont disponibles dans l'onglet **Releases** de ce dépôt.
